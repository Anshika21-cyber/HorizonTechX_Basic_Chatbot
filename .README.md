# Horizon TechX - Basic Chatbot

A rule-based conversational chatbot developed in Python as part of the
Horizon TechX Python Programming Internship.

## Project Overview

This project implements a console-based chatbot that interacts with users
through predefined responses. The chatbot can handle greetings, basic
conversation, chatbot-related questions, current time queries, help
commands, and session termination.

The project demonstrates Python programming fundamentals including
functions, conditional statements, loops, strings, lists, dictionaries,
modules, and user input/output.

## Features

- Interactive command-line chatbot
- Multiple greeting variations
- Basic conversational responses
- Chatbot introduction
- Current time display
- Help command
- Clear screen command
- Conversation history tracking
- Multiple exit commands
- Timestamped chatbot responses
- Handles empty user input
- User-friendly terminal interface

## Available Commands

| Command | Function |
|---|---|
| `hello`, `hi`, `hey` | Greeting |
| `greeting`, `greetings` | Greeting |
| `how are you`, `how are u` | Chatbot status |
| `name`, `who are you` | Chatbot introduction |
| `what can you do` | Display chatbot capabilities |
| `time` | Display current time |
| `thanks`, `thank you` | Thank-you response |
| `help` | Display available commands |
| `clear` | Clear the terminal screen |
| `bye`, `exit`, `quit` | End the chat session |
